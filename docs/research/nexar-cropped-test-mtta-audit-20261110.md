# Nexar cropped-test mTTA audit

Date: 2026-11-10. Scope: the released Nexar test crops and RiskProp `dev` test benchmark; training validation is outside this audit. No benchmark inference was run.

## Findings

1. Nexar's 1,344 test clips are approximately 10 seconds and positive crops stop 0.5, 1.0, or 1.5 seconds before the event. The official competition metric takes one score per clip and computes grouped mAP; it does not specify an mTTA evaluator or a policy for clips whose onset falls after the last frame. [Nexar paper, sections 4.1–4.2](https://arxiv.org/html/2503.03848#S4).
2. RiskProp and TOP describe accepting alerts after anomaly onset for mTTA. Neither source specifies how to reconstruct event times and handle unobservable onset for cropped Nexar test clips. [RiskProp paper, section 4.1](https://arxiv.org/html/2603.27165#S4.SS1); [TOP paper, section 4](https://arxiv.org/html/2510.22260#S4). Equating Nexar `time_of_alert` with anomaly onset is a reasonable candidate, but is an interpretation requiring disclosure.
3. TOP's released Nexar config points test to an annotated validation loader and its hidden-test path exports submission scores. Its onset-gated mTTA implementation does not establish an official implementation for the cropped hidden test. [TOP config](https://github.com/happytianhao/TOP/blob/772c6e57e664ecde83f9d92d0641e1cba99abfb7/configs/accident_anticipation/top/top_nexar.py#L15-L25); [TOP metrics](https://github.com/happytianhao/TOP/blob/772c6e57e664ecde83f9d92d0641e1cba99abfb7/accident_anticipation/metrics.py#L74-L96).
4. PRE-ACT's public Nexar evaluator constructs a virtual score tail by repeating the last observed score until an inferred accident frame, then computes onset-gated mTTA. Its Nexar loader also uses an event-minus-two-seconds onset proxy in the relevant annotation builder. Virtual scores represent an assumption, not model inference on observed frames. The public test script imports `evaluate_predictions` from `run_nexar.py`, while the inspected file defines `evaluate_nexar_official`; end-to-end execution of that public path was not established. [PRE-ACT loader](https://github.com/giddyyupp/PRE-ACT/blob/7257fb7b1c1320ee93957834be49d6162229e388/dataloaders/dataloader_nexar.py#L639-L649); [virtual tail](https://github.com/giddyyupp/PRE-ACT/blob/7257fb7b1c1320ee93957834be49d6162229e388/evaluation/run_nexar.py#L209-L250); [mTTA](https://github.com/giddyyupp/PRE-ACT/blob/7257fb7b1c1320ee93957834be49d6162229e388/evaluation/run_nexar.py#L325-L347); [test entrypoint](https://github.com/giddyyupp/PRE-ACT/blob/7257fb7b1c1320ee93957834be49d6162229e388/test_encoder_anticipation_ddp.py#L556-L575).
5. Local preparation computes each positive test event as `(total_frames - 1) / fps + time_to_accident` and reconstructs clip-relative onset from the metadata. [Preparation code](../../tools/prepare_nexar.py#L75-L89). A direct read of `data/nexar-collision-prediction/annotations.csv` found **672/672** positive test events after the last frame: 284 at +0.5s, 232 at +1.0s, 156 at +1.5s. Onset is after the last frame by more than 1 ms in **16/672** cases. This reconstruction assumes the declared TTE applies to the last observed frame; encoding and frame-time rounding can affect exact boundaries.
6. The current [mTTA helper](../../taa/mtta.py#L59-L73) sets `event_index=0` if no observed timestamp reaches the event. Since all 672 reconstructed positive test events are later than the last timestamp emitted by [the full-video sampler](../../taa/transforms.py#L141-L158), every positive test clip contributes TTA 0, regardless of scores. This is an invalid use of the TOP-style fallback for these crops; it is not evidence that the model missed every collision. The [report template](../../tools/analysis_tools/evaluate_nexar_submission.py#L265-L271) says the full-clip search matches TOP, but this only resembles TOP's `mtta_old`, not its primary onset-gated `mtta`.
7. The local `tools/dist_test.sh` wrapper runs submission inference, full-timeline inference and the combined evaluator automatically for `riskprop_nexar.py`; invoking `tools/test.py` directly has different behavior. [Wrapper](../../tools/dist_test.sh#L28-L81).

## Recommendation: observed alerts with reconstructed event time

- Preserve the observed 10 Hz causal score timeline and its actual timestamps. Infer the test event time using the published TTE and crop endpoint, documenting frame/encoding uncertainty; never substitute the first frame for an event that occurs after the clip.
- Use the Nexar `time_of_alert` mapped into clip time as an explicitly documented onset proxy. For each threshold, search only observed scores at or after that onset and at or before the event. For the first crossing, compute `TTA = event_time_sec - alarm_time_sec`; do not invent scores after the final frame. For example, sample `00009` has observed end ≈9.5425s, mapped onset ≈7.1035s and event ≈10.0425s; an illustrative alert at 9.0s gives TTA ≈1.0425s.
- Keep all positives in the main denominator, assigning zero when no post-onset alarm is observable or detected. Explicitly report the 16 onset-outside-observation clips and also report an analysis restricted to clips with observable onset. Zero is a conservative reporting convention, not proof the model failed after the clip. Neither variant is an officially documented Nexar mTTA.
- Use a declared FAR convention and report realized FAR; the existing threshold-rank cutoff can exceed 0.1 for tied negative scores. Match the chosen threshold grid across compared models. The result is clip-weighted and Nexar crops may share a source video.
- A second, clearly named PRE-ACT-style experiment can repeat the final score to reproduce that implementation's assumption. Apply the same onset proxy, padding, thresholds and dataset to both models before comparing; a virtual-tail score is not evidence of an observed alarm.
- Re-evaluate the same fixed checkpoint and test clips once the convention is implemented, and preserve prior results as historical. Paper-exact equivalence remains unverified until the paper authors' cropped-test protocol is established.
